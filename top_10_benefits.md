# Top 10 Benefits of Mica WebP Optimizer

1. **Optimize images locally** — Convert supported PNG and JPEG/JPG files to WebP with the image APIs exposed by Obsidian.
2. **Review before bulk work** — Scan the current folder or vault and inspect the proposed workload before conversion.
3. **Protect note references** — Update supported wikilinks, Markdown embeds/links, and HTML image references only after a replacement is written and verified.
4. **Keep formatting intact** — Preserve supported captions, aliases, fragments, and titles when a reference path changes.
5. **Choose sensible image settings** — Control quality, maximum dimensions, output folder, watched folders, and metadata policy.
6. **Keep originals by default** — Originals stay in place unless the user chooses Mica's recoverable backup option.
7. **Handle collisions safely** — Use deterministic alternate names instead of overwriting an existing WebP.
8. **Stay in control of batches** — See progress and per-file outcomes; pause, resume, or cancel a run.
9. **Recover recent changes** — Use the saved journal to roll back the most recent batch when current notes and source files allow a safe restore.
10. **Keep media private** — Conversion is local. Optional account/billing requests never include vault paths, note text, or image bytes.

Mica does not promise a fixed size reduction; results depend on the image and the Obsidian host's encoder. Three successful verified conversions are free per local calendar day; paid credits are optional after that allowance.
