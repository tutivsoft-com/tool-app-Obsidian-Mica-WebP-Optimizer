# Mica WebP Optimizer

Version: 3.4.33

Convert PNG and JPEG images to verified WebP files locally while protecting Obsidian note links and original media.

## Features

- Convert new images, the current folder, or the vault using the browser's local encoder.
- Verify every WebP before changing note references.
- Preserve image dimensions by default and optionally resize large images.
- Strip recognized EXIF, device, and location metadata by default.
- Update supported wikilinks, Markdown links, and HTML references without changing captions or fragments.
- Detect filename collisions deterministically and keep originals available for rollback.
- Pause, resume, cancel, and review conversion batches.

## Billing

Account balances, entitlements, and checkout are managed by Constance. The plugin fetches current purchase descriptions, amounts, and availability from the live product catalog. It displays the server-provided offer before checkout. Each successful conversion uses one native conversion unit.

## Installation

In Obsidian, open **Settings → Community plugins → Browse**, search for **Mica WebP Optimizer**, install it, and enable it.
