# Mica WebP Optimizer

Version: 3.4.32

Optimize PNG and JPEG media locally as verified WebP files without breaking note links.

## Pricing and usage

The verified active one-time Paddle offers are:

| Price | Included native units |
| ---: | ---: |
| $1 USD | 100 credits |
| $10 USD | 1,000 credits |

One confirmed image conversion uses one native usage unit. Free and paid amounts are quoted for each conversion. The plugin loads current price and product details from Constance/Paddle and displays the confirmed amount and native units before checkout. Prices and availability shown in Obsidian are current at purchase time.

## Installation

In Obsidian, open **Settings → Community plugins → Browse**, search for **Mica WebP Optimizer**, install it, and enable it.
