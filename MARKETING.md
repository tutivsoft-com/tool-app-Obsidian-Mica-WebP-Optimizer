# Mica WebP Optimizer — Marketing

Version: 3.4.16

## Product positioning

**Optimize images in your Obsidian vault while keeping notes and originals safe.**

Mica converts supported PNG and JPEG images to WebP locally, previews bulk work, verifies each output, and updates supported note references only after it is safe to do so.

## For

Obsidian users whose vaults contain screenshots, diagrams, and photos, and who want to reduce image storage without hand-editing every embed or giving image files to a cloud conversion service.

## Key reasons to choose Mica

- Convert images in the active vault using the Obsidian host's local image APIs.
- Apply folder or vault conversions directly, with optional scan review configured in Settings.
- Preserve supported wikilink, Markdown, and HTML references, including their captions and aliases.
- Keep originals by default, with an optional recoverable backup and rollback journal.
- Strip recognized location/device metadata by default and see per-file outcomes in a local log.
- Use image processing without an AI account; optional billing applies only to successful conversions after the daily free allowance.

## Short description

Local WebP optimization for Obsidian: review a batch, verify every output, and keep image links and originals recoverable.

## Claims and limitations

Mica does not promise a fixed compression ratio or visual result. WebP size and quality depend on the input image and the encoder available in Obsidian. Near-lossless is the encoder's highest-quality mode, not a separate lossless codec. Metadata preservation is best effort; stripping is the default.
